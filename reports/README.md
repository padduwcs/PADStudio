# Acceptance reports

Các file trong thư mục này là evidence của những lần acceptance/pilot đã chạy tại thời điểm ghi
trong từng report. Chúng được giữ nguyên để truy vết và không phải dashboard trạng thái hiện hành.

- Không sửa số test, project ID, Result ID hoặc kết luận trong report cũ để khớp code mới.
- Không suy ra sản phẩm đã hoàn chỉnh chỉ vì một acceptance fixture hoặc một lát cắt practical pass.
- Khi cần trạng thái phát triển gần nhất, đọc
  [`../docs/build/PADSTUDIO-DEVELOPMENT-STATUS.md`](../docs/build/PADSTUDIO-DEVELOPMENT-STATUS.md)
  và chạy lại lệnh kiểm chứng liên quan.
- Report mới phải ghi rõ ngày, phạm vi, lệnh chạy, giới hạn và loại evidence; fixture phải được phân
  biệt với user/provider/corpus evidence thật.
