# Font giao diện PADStudio

**Manrope**, variable weight 200–800, có glyph tiếng Việt. Bản TTF được tải nguyên byte từ [Google Fonts](https://github.com/google/fonts/tree/main/ofl/manrope) ngày 2026-10-05.

- Nguồn: https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/Manrope%5Bwght%5D.ttf
- SHA-256: `3ae11c49db0455a3cc33e37d380f20fdb8c7f8b41dc07625c177e3d87a9d6ae6`
- Giấy phép SIL Open Font License 1.1: [OFL.txt](OFL.txt), giữ nguyên bản quyền đi kèm.

Web phục vụ font từ chính PADStudio; không gọi CDN font trong lúc sử dụng. Weight 400 dùng cho nội dung, 500 cho nhãn/nút, 600 cho tiêu đề và trạng thái được chọn.
