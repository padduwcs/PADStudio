# Stock sourcing

Use stock only for a named shot or sound need, not as generic filler.

1. Search by subject, action, setting, orientation and media type. Keep multiple candidates when the choice affects tone.
2. Open the original source page. Verify creator, license, permitted use and any attribution requirement; search metadata alone is not rights clearance.
3. Reject weak matches, watermarks, misleading context, incompatible lighting or framing, and assets whose source cannot be audited.
4. Acquire the selected HTTPS asset through `media.acquire`. This preserves the original page, expected media type, attribution and exact downloaded bytes.
5. Inspect the registered asset before putting it into a sequence. Record the shot need and selection rationale in the relevant artifact or Decision.

Never treat a search result URL as a durable project input and never claim that Wikimedia availability alone proves suitability for release.
