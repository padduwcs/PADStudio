# Adaptive planning

## Use when

The Agent has enough understanding to organize work, or new evidence makes the current plan inaccurate.

## Method

1. Plan from active artifacts and evidence, not from a universal pipeline.
2. Give every work item a purpose, expected outcome, dependencies, applicable skills, review need, and approval impact.
3. Use an optional template only as a starting hypothesis.
4. Revise the workflow when reality changes; preserve the previous revision and state the reason.
5. Add branches or rework items instead of rewriting history.

## Standard

The graph must be acyclic, executable from its dependencies, and no more detailed than current evidence supports. PADStudio validates and preserves the plan; the Agent owns the creative choice of what work belongs in it.
