# Creative direction

## Use when

The work has meaningful choices of concept, tone, rhythm, visual language, narrative, or audience experience.

## Method

1. Start from the active brief and source understanding.
2. Generate genuinely distinct directions, not cosmetic variants.
3. Compare them against intent, constraints, effort, risk, and review criteria.
4. Store 2 to 5 comparable options as a version `1.0` `creative.proposal`; reference the active `project.brief` and identify one recommendation with reasons.
5. After the user chooses, store a version `1.0` `creative.direction` that references the exact proposal and option. A direct direction may instead reference the brief when comparison is genuinely unnecessary.
6. Express taste as reusable principles, explicit avoidances, review criteria, and an optional bounded sample plan.

The exact fields, provenance, revision, approval, and compatibility rules are defined in `docs/build/CREATIVE-DIRECTION-SPEC.md`.

## Standard

A direction should guide later decisions while leaving room for execution-level creativity. Do not turn it into a frozen shot list prematurely.
