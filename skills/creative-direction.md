# Creative direction

## Use when

The work has meaningful choices of concept, tone, rhythm, visual language, narrative, or audience experience.

## Method

1. Start from the active brief and source understanding.
2. Compare the proposed form with salient source material and the requested outcome before production effort. If a source is deliberately omitted or a long source is reduced to a short sample, make that choice and its purpose explicit. A short sample must not be presented as a complete explanatory preview.
3. Generate genuinely distinct directions when comparison would improve the choice, not cosmetic variants.
4. Compare them against intent, constraints, effort, risk, and review criteria.
5. When comparison is needed, store 2 to 5 options as a version `1.0` `creative.proposal`; reference the active `project.brief` and identify one recommendation with reasons.
6. After the user chooses, or when the user has delegated the creative choice to the Agent, store a version `1.0` `creative.direction` with the selected option and reason. A direct direction may instead reference the brief when comparison is genuinely unnecessary. Do not require the user to choose among options they asked the Agent to choose.
7. Express taste as reusable principles, explicit avoidances, review criteria, and an optional bounded sample plan.

The exact fields, provenance, revision, approval, and compatibility rules are defined in `docs/build/CREATIVE-DIRECTION-SPEC.md`.

## Standard

A direction should guide later decisions while leaving room for execution-level creativity. Do not turn it into a frozen shot list prematurely.
