# Creative direction

## Use when

The work has meaningful choices of concept, tone, rhythm, visual language, narrative, or audience experience.

## Method

1. Start from the active brief and source understanding.
2. Generate genuinely distinct directions, not cosmetic variants.
3. Compare them against intent, constraints, effort, risk, and review criteria.
4. Recommend one direction and explain the trade-off; request approval only when the impact warrants it.
5. Express taste as reusable principles and explicit avoidances in a `creative.direction` artifact.

## Standard

A direction should guide later decisions while leaving room for execution-level creativity. Do not turn it into a frozen shot list prematurely.
