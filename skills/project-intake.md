# Project intake

## Use when

The project intent, audience, desired outcome, constraints, or available material are not yet dependable enough to plan work.

## Method

1. Read existing project state before asking anything.
2. Extract what is known from the request and evidence; label assumptions explicitly.
3. Ask only questions whose answers can materially change the direction or scope.
4. Record the result as a `project.brief` artifact with purpose, audience, desired outcome, constraints, known facts, assumptions, and open questions.

## Standard

The brief is useful when another Agent can explain what success means, what must not change, and what remains uncertain without replaying the conversation.
